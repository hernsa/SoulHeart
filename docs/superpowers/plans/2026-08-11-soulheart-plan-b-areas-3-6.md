# SoulHeart Plan B — Areas 3-6 (Echo, Hometown, Canon, Cracks) Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Extend the walkable world from 2 rooms to 6 by adding Echo, Hometown, Canon, and Cracks rooms (each 40×30, with own tile style, encounters, save point, doors, Wisp companion, and music), plus 2 newly composed area themes (Echo, Hometown) wired into the audio autoload. Shippable result: Ruins → Snowdin → Echo → Hometown → Canon → Cracks fully walkable with working doors both directions.

**Architecture:**
- **Tile styles:** `GameTiles` gains `ECHO_STYLE`, `HOMETOWN_STYLE`, `CANON_STYLE`, `CRACKS_STYLE` consts + a `AREA_STYLES` array. `_atlas_texture(style)` already loads `res://assets/sprites/tiles/{style}_floor.png` + `{style}_floor_b.png` (16×16 seamless) — so a new style = 2 PNGs + 1 const. PNGs generated by a deterministic tool script (torus-indexed noise guarantees seamless edges).
- **Rooms:** 4 new room scripts + 4 new scenes, structurally identical to `grumble_woods.gd` (LAYOUT const → `MapBuilder.parse_layout` → `build_room(grid, STYLE)` → spawn player/encounters/door/props/wisp → flags → music → fade). Multi-door support via a `DOOR_TARGETS: Array[Dictionary]` const (`{"target_room": "...", "target_spawn": Vector2}`), consumed by a looping `_spawn_door`.
- **Doors:** `door.gd` unchanged (already takes full scene path + spawn). Door chain: GrumbleWoods gains a 2nd door → Echo; Echo ↔ Hometown ↔ Canon ↔ Cracks both directions. All spawns at `(40,232)` or `(600,232)` (two tiles inside the door you enter).
- **Wisp:** each new room calls `_spawn_wisp` (Plan A pattern) with `WispState.set_area("echo"|"hometown"|"canon"|"cracks")` + `WispDialogue.get_line(<area>)`; `WispDialogue` gains 4 new contexts backed by 4 new `.dlg` files.
- **Music:** `tools/gen_area_music.gd` synthesizes 8-note motifs → `AudioStreamWAV.save_to_wav` → `mus_echo.wav` + `mus_hometown.wav`. `audio.gd` MUSIC dict gains `"echo"`/`"hometown"` preloads, plus a new `setup_stream_loop(stream)` static that sets `LOOP_FORWARD` on `AudioStreamWAV` (the existing loop branch only handles OggVorbis). Canon reuses `"grumble"`, Cracks reuses `"drizzle"` as placeholders (Plan D adds real themes).

**Tech Stack:** Godot 4.4.1, GDScript, existing autoloads (GameState, Sprites, Audio, DialogueParser, Fade), `tests/run_all.gd` runner (scans `res://tests/*.gd`, `test_*` funcs on RefCounted), `TestHelper.eq/is_true`. `--import` pass required after adding new PNGs/WAVs/class_name scripts (per-repo `.godot` cache lesson from Plan A T3/T4).

## Global Constraints

These come from the spec (2026-08-11-soulheart-full-game-design.md §7 Plan B) and the established engine conventions. Every task's requirements implicitly include this section.

- **Plan B scope ONLY:** 4 new rooms, 4 tile styles, door transitions, 2 area themes, mob placements. NO bosses (Plan C), NO endings/edit-events/save-point-echoes (Plan D), NO new NPCs in new rooms (Plan D adds The Reader, The Echo).
- **Room script shape must match existing `drizzle_fields.gd`/`grumble_woods.gd`** exactly: `extends Node2D`, `class_name`, `ROOM_PATH`, `ENCOUNTER_ENEMIES: Array[String]`, `LAYOUT` (40-col × 30-row ascii string, border `#`), `_spawn_point` (save_point flag check), `_spawn_player` (+Camera2D centered + `make_current`), `_spawn_wisp`, `_spawn_props`, `_spawn_encounters` (cycle `i % ENCOUNTER_ENEMIES.size()`), `_spawn_door`, `GameState.set_flag("current_room", ROOM_PATH)`, `Audio.play_music(...)`, `Audio.play_sfx("door_close")`, `Fade.fade_from_black(0.67)`.
- **Layout marker semantics** (LayoutParser): `#` wall (invisible, has collision), `.` floor, `P` player start, `E` encounter, `S` save point, `D` door, `T` tree (spawns `RoomTree` = pine sprite). Doors appear in the `doors` array in scan order (top-to-bottom, left-to-right); `DOOR_TARGETS[i % DOOR_TARGETS.size()]` maps door → target.
- **Tile styles:** a style is ONLY a string constant + `assets/sprites/tiles/{style}_floor.png` + `{style}_floor_b.png` (16×16, seamless: pixel(0,y)==pixel(15,y) and pixel(x,0)==pixel(x,15), and B variant must differ from A). `GameTiles._atlas_texture` does the rest. New style consts MUST also be added to a `GameTiles.AREA_STYLES` array (used by tests).
- **Door targets:** `door.gd` does `change_scene_to_file(target_room)` — `target_room` must be a FULL `res://` path. Every target scene file MUST exist at the time `_spawn_door` runs. `target_spawn` must be a walkable floor cell.
- **Music:** `audio.gd` MUSIC entries are `preload(...)` consts — parse-time. A new key cannot be added until the file exists on disk AND is imported. `AudioStreamWAV` from `save_to_wav` does NOT persist loop state — looping must be set at runtime via `Audio.setup_stream_loop(stream)`.
- **Wisp:** `WispState.set_area(<area id>)` ids: `"echo"`, `"hometown"`, `"canon"`, `"cracks"`. `WispDialogue.get_line(context)` must handle these 4 new contexts (fallback exists but must not be exercised in the new rooms).
- **Existing test test_floors.gd** hardcodes ruins/snowdin file lists + style loops — it must be extended to include the 4 new styles (same file, Task 1).
- **TDD gate:** every task writes a failing test, makes it pass, runs FULL suite green, then commits. No red commits. Suite command + import + kill-hung-godot patterns are established (see Task 1).
- **--import discipline:** run `godot --headless --import` after adding ANY new PNG/WAV/GDScript-with-class_name, before running the suite.
- **Frequent commits**, Conventional Commits (`feat:`, `test:`, `fix:`, `chore:`). One commit per task minimum.
- **No emojis in code/comments/commits.** GDScript: tabs for indentation (matches existing files), `class_name` at top, no `@tool` in room scripts (only generators use it).
- **Existing rooms keep working:** DrizzleFields (1 door → GrumbleWoods) and GrumbleWoods (2 doors: → Echo, → DrizzleFields). Their encounters/music/NPCs unchanged.

- [ ] **Step 4: Create `tools/gen_area_tiles.gd`**

```gdscript
@tool
extends SceneTree

# Deterministic torus-noise 16x16 floor tiles. Seamless by construction:
# the noise hash is periodic in both axes mod 16, so edges always match.

const STYLES := {
    "echo":     {"base": Color8(38, 42, 72),   "hi": Color8(58, 64, 104)},
    "hometown": {"base": Color8(92, 74, 54),   "hi": Color8(116, 94, 68)},
    "canon":    {"base": Color8(70, 56, 38),   "hi": Color8(94, 76, 52)},
    "cracks":   {"base": Color8(22, 22, 32),   "hi": Color8(48, 40, 66)},
}

func _init() -> void:
    for style in STYLES:
        var cfg := STYLES[style]
        _make(style, cfg["base"], cfg["hi"], 0)
        _make(style, cfg["base"], cfg["hi"], 7)
    quit()

func _hash(x: int, y: int, salt: int) -> int:
    var h := (x * 374761393 + y * 668265263 + salt * 1442695041) & 0x7fffffff
    h = ((h >> 13) ^ h) * 1274126177 & 0x7fffffff
    return h

func _make(style: String, base: Color8, hi: Color8, salt: int) -> void:
    var img := Image.create(16, 16, false, Image.FORMAT_RGBA8)
    for y in 16:
        for x in 16:
            var n := float(_hash(x, y, salt)) / float(0x7fffffff)
            var v := 0.55 + 0.45 * n
            var c := Color8(int(base.r * v), int(base.g * v), int(base.b * v))
            if (x + y + salt) % 5 == 0:
                c = Color8(int(hi.r * v), int(hi.g * v), int(hi.b * v))
            img.set_pixel(x, y, c)
    var dir_path := "res://assets/sprites/tiles/"
    DirAccess.make_dir_recursive_absolute(ProjectSettings.globalize_path(dir_path))
    var variant := "floor" if salt == 0 else "floor_b"
    var err := img.save_png("res://assets/sprites/tiles/%s_%s.png" % [style, variant])
    if err != OK:
        push_error("Failed to save %s_%s.png: %d" % [style, variant, err])
```

```gdscript
	"echo": [440.0, 349.23, 293.66, 220.0, 261.63, 329.63, 293.66, 220.0],
	"hometown": [261.63, 329.63, 392.0, 523.25, 392.0, 329.63, 261.63, 392.0],
}

const RATE := 22050
const NOTE_LEN := 0.22
const GAP := 0.03

func _init() -> void:
	for id in MOTIFS:
		_save(id)
	quit()

func _save(id: String) -> void:
	var freqs: Array = MOTIFS[id]
	var per_note := int((NOTE_LEN + GAP) * RATE)
	var total := per_note * freqs.size()
	var data := PackedByteArray()
	data.resize(total)
	var idx := 0
	for f: float in freqs:
		var n := int(NOTE_LEN * RATE)
		for i in n:
			var t := float(i) / float(RATE)
			var env := exp(-2.2 * t)
			var s := 0.6 * sin(TAU * f * t) + 0.4 * sin(TAU * f * 2.0 * t) * 0.35
			data[idx] = int(clamp((s * env + 1.0) * 127.5, 0.0, 255.0))
			idx += 1
		for i in int(GAP * RATE):
			data[idx] = 128
			idx += 1
	var wav := AudioStreamWAV.new()
	wav.format = AudioStreamWAV.FORMAT_8_BITS
	wav.mix_rate = RATE
	wav.data = data
	var err := wav.save_to_wav("res://assets/audio/music/mus_%s.wav" % id)
	if err != OK:
		push_error("save_to_wav failed for %s: %d" % [id, err])
```
